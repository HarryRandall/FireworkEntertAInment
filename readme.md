# Firework EntertAInment

An AI tool for designing real consumer firework shows.

Built in partnership with [ICON Pyrotechnics International](http://www.iconpyro.com) as part of COMP3500.

## About

This repository contains the Firework EntertAInment project and supporting prototype components.  
One current component is the audio analysis script at `prototypes/audio-analyser/`, used to extract musical structure and cue timings from songs.

## Repository Structure

```
docs/                      — project documentation and meeting notes
data/media/audio/          — example tracks used by the analyser
prototypes/audio-analyser/ — ShowCrafter script + requirements + component README
prototypes/site-mockup/    — static website mockup pages
```

## Components

- `prototypes/audio-analyser/`: song analysis pipeline (MIR prototype)
