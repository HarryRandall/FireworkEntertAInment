ShowCrafter · in-store consumer flow

Two QR entry points, one streamlined kiosk experience

ShowCrafter stays a web app throughout: each QR code opens the flow straight in the shopper's own mobile browser, no install and no account. No library browsing, no admin surface. The AI always proposes a show built from real shelf stock first; a person only reaches individual-product picking if they choose to.

Marker green = AI-driven action Lock = value fixed by the scan, not editable Pack badge = which assortment the show was built from

Assortment-first by default

Both entry points generate from pre-built, in-stock packs before ever touching individual products, so a first-time shopper always gets a coherent, in-budget show on the first try.

One shared recovery pattern

Whichever way someone entered, dissatisfaction resolves through the same sheet: reprompt for another assortment, adjust an input and regenerate, or switch to custom mode, where the AI keeps designing but chooses from individual products instead of a prebuilt pack.

Fewer decisions per scan

The storefront code asks three questions; the on-product code asks one. Budget and pack context come for free from wherever the phone was scanned.
