## 📝 Planning & Documentation

- **[Notion](https://www.notion.so/)** - single source of truth for project documentation, meeting minutes, reflections, and this workspace itself. Synced into the GitHub repo via a custom GitHub Action.

- **[Linear](https://linear.app/)** - issue tracking, sprint cycles, and backlog grooming. Every PR references a Linear issue.

- **[Microsoft Teams](https://www.microsoft.com/en-au/microsoft-teams)** - weekly stakeholder meetings with Robert Foti (recorded and transcribed).

- **[Discord](https://discord.com/)** - day-to-day team communication and voice calls.

- **WhatsApp** - async out-of-band communication with Robert between meetings.

## 💻 Development Platform

![my-stack-diagram(1)](192fe9e7_my-stack-diagram(1).png)

- **[GitHub](https://github.com/)** - version control, PR reviews, CI/CD via GitHub Actions. Repository: `[HarryRandall/FireworkEntertAInment](https://github.com/HarryRandall/FireworkEntertAInment)`.

- **[Next.js 15](https://nextjs.org/)** - full-stack React framework powering the ShowCrafter web platform.

- **[TypeScript](https://www.typescriptlang.org/)** - primary language for the web platform.

- **[Tailwind CSS v4](https://tailwindcss.com/)** - utility-first styling for the Next.js app.

- **[Vercel](https://vercel.com/)** - hosting and preview deployments for the Next.js app.

- **[Supabase](https://supabase.com/)** - Postgres database plus auth for the firework catalogue and user accounts.

## 🎵 Audio & AI

- **[Python 3](https://www.python.org/)** - audio analyser prototype language.

- **[librosa](https://librosa.org/)** - Music Information Retrieval library for beat tracking, onset detection, energy estimation, and spectral features.

- **OpenAI API** (planned) - large-language-model backbone for the show-choreography agent and natural-language refinement prompts.

---

## 🎆 Firework Design & Simulation

- **[Finale 3D](https://finale3d.com/)** - professional firework show design and simulation software; MVP export target (Generic CSV format).

- **[GLOW Fireworks](https://glowfireworks.com/)** - retail-grade 3D show builder embedded on retailer websites; reference for the long-term consumer experience.

- **[Ignite Firing Systems](https://ignitefiringsystem.com/)** - electronic firing-system hardware and companion app; Phase 3 integration target.

- **[Godot](https://godotengine.org/)** - spike candidate for a browser-native firework simulator ([FIR-28](https://linear.app/fireworkentertainment/issue/FIR-28/write-research-methods-for-firework-simulation)).
