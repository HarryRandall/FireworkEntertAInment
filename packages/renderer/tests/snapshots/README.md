# Historical poster references

These 160 by 100 pixel PNGs are retained for owner visual reference. The browser
screenshot matrices and nightly poster comparison workflow have been removed from
the five-minute gate. There is no active baseline-update command for this directory.
Do not treat the retained files as current visual approval.

Package tests cover deterministic poster seeds, framing and the shared-context API.
`tests/browser/studio-journey.spec.ts` verifies all four actual uploaded poster
formats; `tests/browser/render-smoke.spec.ts` checks changing live pixels and exact
paused-seek replay. Neither replaces device/driver parity or owner visual review.

See [the browser inventory](../../../../docs/testing/browser-suite.md) and
[Development](../../../../docs/development.md) for the current gate and commands.
